1. INTRODUCTION                                         *gauntlet-introduction*

gauntlet.nvim is a user interface for working on pull requests without leaving
Neovim.

This is an empty skeleton: it installs and loads, and does nothing else yet.

==============================================================================
2. INSTALLATION                                         *gauntlet-installation*

With lazy.nvim: >lua

    {
      "Loki-Astari/gauntlet.nvim",
      config = function()
        require("gauntlet").setup({})
      end,
    }
<
==============================================================================
3. CONFIGURATION                                       *gauntlet-configuration*

setup() takes an options table, merged over the defaults: >lua

    require("gauntlet").setup({})
<
There are no options yet.
