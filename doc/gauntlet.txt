==============================================================================
1. INTRODUCTION                                         *gauntlet-introduction*

gauntlet.nvim runs a pull request through review without leaving the editor:
fetch the PR, read the diff in Neovim, and have an agent CLI review it.

This is an early skeleton - see |gauntlet-commands| for what exists today.

==============================================================================
2. INSTALLATION                                         *gauntlet-installation*

With lazy.nvim: >lua

    {
      "Loki-Astari/gauntlet.nvim",
      cmd = "Gauntlet",
      opts = {},
    }
<
Run `:checkhealth gauntlet` to verify the agent and `gh` CLIs are present.

==============================================================================
3. CONFIGURATION                                       *gauntlet-configuration*

Defaults: >lua

    require("gauntlet").setup({
      agent = "claude",       -- symbolic name of the reviewing agent CLI
      known_agents = {        -- symbolic name -> executable
        claude = "claude",
        codex  = "codex",
      },
      forge = "github",       -- PR source; github uses the `gh` CLI
    })
<
==============================================================================
